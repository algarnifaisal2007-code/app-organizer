# منظّم التطبيقات · App Organizer

تطبيق أندرويد عربي بالكامل (من اليمين إلى اليسار) يرتّب تطبيقات جوالك تلقائيًا في فئات أنيقة ملوّنة.

## المميزات

- **تصنيف تلقائي ذكي** لكل التطبيقات المثبتة في فئات مثل: إسلامي، خدمات حكومية، مالية وبنوك، طعام وتوصيل، تسوق، مراسلة، تواصل اجتماعي، ألعاب، فيديو، موسيقى، تعليم، إنتاجية، أدوات، وغيرها — مع دعم تطبيقات محلية (أبشر، توكلنا، نفاذ، الراجحي، جاهز، هنقرستيشن…).
- **بطاقات فئات بتدرّجات لونية** تعرض عدد التطبيقات ومعاينة لأيقوناتها.
- **المفضلة** و**الأكثر استخدامًا** و**أُضيفت حديثًا** في أعلى الشاشة الرئيسية.
- **بحث عربي ذكي** يتجاهل التشكيل ويوحّد (أ/إ/آ ← ا، ة ← ه، ى ← ي)، ويبحث في أسماء الفئات أيضًا.
- **ضغطة مطوّلة على أي تطبيق** لفتحه، إضافته للمفضلة، نقله لفئة أخرى، عرض معلوماته، أو إلغاء تثبيته.
- **ترتيب داخل الفئة**: أبجديًا، الأحدث تثبيتًا، الأكثر استخدامًا.
- واجهة داكنة عصرية مبنية بـ Jetpack Compose و Material 3.

## التحميل

كل دفعة (push) تبني ملف APK تلقائيًا عبر GitHub Actions:
**Actions ← Build APK ← آخر تشغيل ← Artifacts ← `app-organizer-debug`**، ثم ثبّته على جوالك.

## البناء محليًا

يتطلب Android Studio (أو Android SDK) و JDK 17:

```bash
./gradlew assembleDebug
# الملف الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## البنية

```
app/src/main/java/com/faisal/apporganizer/
├── MainActivity.kt
├── data/
│   ├── Category.kt       # الفئات وألوانها وكلماتها المفتاحية
│   ├── Classifier.kt     # التصنيف التلقائي وتوحيد النص العربي
│   ├── AppRepository.kt  # قراءة التطبيقات المثبتة
│   ├── Prefs.kt          # المفضلة والفئات المخصصة وعدد مرات الفتح
│   └── AppActions.kt     # فتح / معلومات / إلغاء تثبيت
└── ui/
    ├── OrganizerViewModel.kt
    ├── OrganizerApp.kt   # الشاشات والمكوّنات
    └── theme/Theme.kt
```
